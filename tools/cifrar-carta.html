Cifrar la carta

Escribe aquí la carta y el código de 6 dígitos. La página genera el archivo cifrado carta.enc.json. Todo ocurre en tu navegador: nada se envía a ningún servidor.

Antes de empezar
  • Abre este archivo haciendo doble clic desde tu computadora (no hace falta subirlo a ningún sitio).
  • El código no se puede recuperar. Si lo pierdes, hay que cifrar la carta otra vez. Anótalo en un lugar privado, fuera del repositorio.
  • Guarda también el texto de la carta en un archivo privado tuyo. Esta página no lo guarda: al cerrarla se pierde.

Listo. Qué hacer con el archivo

Descargar carta.enc.json
  1. Guarda el archivo como vj/data/carta.enc.json (reemplaza el que ya está).
  2. En sw.js sube el número de VERSION (por ejemplo vj-v3).
  3. Sube los cambios a GitHub (git add ., git commit, git push).
  4. Prueba en tu teléfono con la fecha forzada: …/vj/?fecha=2020-01-01T00:00:00Z#/carta
